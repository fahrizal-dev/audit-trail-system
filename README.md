# Audit Trail System

## Overview
Web-based system for tracking user activities and system logs.

## Features
- User authentication
- Activity logging
- Dashboard monitoring
- API logging

## Tech Stack
- PHP
- MySQL
- JavaScript

## Setup
1. Import database
2. Configure database connection
3. Run on localhost
