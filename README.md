# Audit Trail System

## 📌 Overview
Audit Trail System is a web-based application to track and monitor user activities within a system.

## ⚙️ Features
- User Authentication (Login System)
- Activity Logging (Create, Update, Delete tracking)
- API Logging
- Dashboard Monitoring

## 🛠️ Tech Stack
- PHP (Native / CodeIgniter)
- MySQL
- JavaScript
- Bootstrap / Tailwind (sesuaikan)

## 🧩 System Architecture
This system records every user action into a log table, allowing administrators to monitor changes and ensure data integrity.

## 🚀 How to Run
1. Clone this repository
2. Import database (`database.sql`)
3. Configure database connection
4. Run using XAMPP / localhost
